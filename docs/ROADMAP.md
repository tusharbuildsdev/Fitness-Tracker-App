# Roadmap

Return to the [README](../README.md).

The roadmap communicates direction, not a release guarantee. Priorities may change based on user feedback, accessibility needs, security, and maintainability.

## Current foundation

- Workout management
- Steps, calories, water, sleep, and weight tracking
- Analytics visualizations and progress comparisons
- Profile, goals summary, theme, privacy, and notification settings
- Firebase and local-storage service boundaries

## Planned focus areas

| Theme | Potential outcomes |
| --- | --- |
| Reliability | Automated tests for schemas, services, and critical user flows; stronger offline and error states. |
| Accessibility | Screen-reader audits, contrast checks, reduced-motion support, and device-size validation. |
| Insights | More configurable targets, trend explanations, and meaningful progress summaries. |
| Data control | Export, retention, and account/data-management workflows designed with privacy in mind. |
| Product polish | Refined onboarding, UI consistency, and documented release automation. |

## Proposing work

Search existing issues and open a feature request using the repository template. Explain the user problem, desired behavior, alternatives considered, and any privacy or data impact. For implementation details, read [Contributing](../CONTRIBUTING.md).
